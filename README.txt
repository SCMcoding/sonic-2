SIMPLE HTML WEBSITE - BEGINNER TEMPLATE

Open index.html to start. The navigation bar leads to about.html, gallery.html and contact.html.

COLORS
Open style.css, find :root near the top, and change any hex color beginning with #. All default colors are already set.

BANNER
Replace images/banner.png with your own PNG using the same filename.

GALLERY
Put photos into images/gallery/. Replace the three sample images or change the src paths inside gallery.html.

Keep index.html, about.html, gallery.html, contact.html, style.css, and the images folder together.
